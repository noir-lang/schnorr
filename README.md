# Schnorr

> [!WARNING]
> **This library is experimental software. It has not been fully audited and is not guaranteed to be secure. Expect bugs!**
>
> schnorr is provided "as is", without warranty of any kind (see [LICENSE](LICENSE)). Bugs in this library can lead to under-constrained circuits, allowing invalid proofs to be accepted. Do not rely on it to protect real assets or sensitive data without your own independent review.

A Noir implementation for verification of Schnorr signatures.

## Noir version compatibility

This library is tested to work as of Noir version 1.0.0-beta.0.
